# D-039 · 현재 로컬 하네스 제거, 원격 환경 구성 시 재구축 (2026-08-06)

> [ADR 인덱스](README.md) · 결정 ID: D-039

- **결정**: 현재 워크스페이스에서는 `sift-harness` 레포와 그 심링크·역할 런처·권한 프로파일을 사용하지 않는다.
- **결정**: 현재 개발은 `sift-api`와 `sift-docs`를 중심으로 진행한다. 프로젝트 공통 규칙은 루트의 최소 `AGENTS.md`에 둔다.
- **결정**: 원격 환경이 필요해지는 시점에 하네스를 새 요구사항으로 재설계·구축한다. 기존 하네스의 bootstrap·역할 분리·원격 제어 구조는 참고 기록으로만 보존한다.
- **비고**: D-034~D-038의 하네스 운영 결정은 당시 운영 이력으로 보존하며, 현재 활성 운영 규칙으로 해석하지 않는다.
