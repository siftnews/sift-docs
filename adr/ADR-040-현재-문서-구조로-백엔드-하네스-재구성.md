# D-040 · 현재 문서 구조로 백엔드 하네스 재구성 (2026-08-06)

> [ADR 인덱스](README.md) · 결정 ID: D-040

- **결정**: 외부 도구 전용 디렉터리를 도입하지 않고, `sift-docs` 루트의 `references/`·`checklists/`·`workflows/`·`prompts/`·`adr/`를 활성 하네스 구조로 사용한다.
- **결정**: 과거 역할 런처와 로컬 하네스는 복원하지 않는다. 기존 역할 문서 삭제는 유지하며, 협업 경계는 현재 에이전트 역할과 사용자 결정 게이트로 정의한다.
- **이유**: 현재 저장소의 실제 문서와 실행 환경에 맞는 단일 구조를 유지하고, 존재하지 않는 런처·경로를 운영 규칙으로 광고하지 않기 위해서다.
