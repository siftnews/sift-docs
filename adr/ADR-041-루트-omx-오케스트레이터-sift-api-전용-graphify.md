# D-041 · 루트 OMX 오케스트레이터 + `sift-api` 전용 Graphify (2026-08-06)

> [ADR 인덱스](README.md) · 결정 ID: D-041

- **결정**: 일반 작업 세션은 비-Git 워크스페이스 루트 `siftnews/`에서 시작한다. 주 세션은 오케스트레이터로서 범위 확정, 하위 작업 배분, 결과 통합, 최종 검증을 책임지고, 독립적인 읽기 전용 탐색·검토는 OMX로 병렬화한다.
- **결정**: 같은 하위 저장소의 순차 의존 구현은 한 소유자가 수행한다. 병렬 구현이 필요하면 대상 저장소에서 worktree와 파일 소유권을 분리하고, Git·빌드·테스트 명령은 해당 하위 저장소에서 실행한다.
- **결정**: Graphify 파생 인덱스는 코드 탐색이 필요한 `sift-api`에만 둔다. `sift-docs`는 설계·결정 원본으로 직접 읽으며 Graphify 인덱스와 Git 훅을 두지 않는다.
- **이유**: 루트는 여러 하위 저장소를 조율하는 실행 경계이고 Git 저장소가 아니다. 코드 관계 그래프의 효용은 `sift-api`에 집중되는 반면, 문서 레포까지 중복 인덱싱하면 갱신 경로와 파생 산출물만 늘어난다.
