# D-034 · 세션 역할 3분할 — 조율·구현·검수를 권한으로 강제 (2026-08-04 · D-016 전면 개정 · D-026 쓰기 주인 항목 개정)

> [ADR 인덱스](README.md) · 결정 ID: D-034

- **결정**: 세션을 **🧭 조율(orchestrator) · 🔧 구현(implementer) · 👀 검수(reviewer)** 세 역할로 나누고, 경계를 지침이 아니라 **권한 프로파일로 강제**한다. ① 각 역할은 전용 런처(`sift-orch`·`sift-impl`·`sift-review` — 한 스크립트 `bin/sift-role`을 세 이름으로 링크)로 기동하며, 런처가 `.claude/roles/{역할}.settings.json`과 역할 앵커(`sift-docs/roles/{ROLE}.md`를 읽으라는 지시)를 주입한다. ② **루프 문서(STATE·BACKLOG·TASKS·DECISIONS) 쓰기 주인은 조율 세션**으로 이관한다(D-016의 "구현 세션 전담" 개정) — 구현 세션은 `Edit(sift-docs/**)` deny로 **막힌다**. ③ 구현 세션은 `gh issue create` deny(이슈 발행은 조율), 조율 세션은 `Edit(sift-api/**)`·`gh pr create` deny(코드·PR은 구현), 검수 세션은 **모든 파일 편집과 git/gh 쓰기 deny**. ④ 세션 간 인계는 GitHub(이슈·PR)이 매체이고, GitHub에 남길 수 없는 것만 인계함 `.handoff/`를 쓴다 — `reviews/`(👀→🔧 검수 리포트), `notes/`(🔧→🧭 루프 문서 반영 요청). 상세 절차는 `sift-docs/roles/` 3파일이 원본(HARNESS §0.8은 요약+링크).
- **이유**: 사용자 결정(2026-08-04). 역할 분리의 필요가 세 번 실측됐다 — ① §0.8이 "자기 코드 자기 리뷰는 편향된다"고 적어 놓고 실제로는 구현 세션이 `/code-review`와 CodeRabbit 지적 판정까지 겸했다(검수 역할이 문서상으로만 존재) ② CodeRabbit 리뷰 공백이 **4회 재발**(PR #22·#28·#38·#40)했는데 rate limit이 걸려도 체크는 `SUCCESS`로 떠, 외부 리뷰가 비어도 알아챌 독립된 눈이 없었다 ③ 루프 문서 다중 쓰기가 실제 사고로 이어졌다(2026-07-26 — fetch 없이 로컬 사본을 진실로 취급해 D-031 중복 작성, 커밋 2개 폐기). 하네스 원칙 2("2번 했으면 박제한다")의 적용이며, D-027로 가드 훅을 폐지하며 후퇴했던 **"기억이 아니라 장치로 강제"(D-023)를 권한 계층에서 회복**한 것이기도 하다 — 훅과 달리 권한 규칙은 우회 경로가 없다.
- **보강 (2026-08-04)**: 「자가검증을 피하고 싶다」는 요구로 **4번째 역할(검증 세션) 분리를 검토했으나 불필요로 결론**. 자가검증을 세 층으로 쪼개 보면 ① 실행(`build`·`test`)은 CI가 이미 하고 ② **테스트 작성은 TDD 관행상 구현자의 일이며**(테스트를 먼저 써서 실패를 보고 구현하는 것이 TDD의 본질) ③ **"이 테스트로 충분한가"의 판정만이 분리 대상인데 그것은 이미 검수 세션 몫**이다. 대신 결함 하나를 고쳤다 — 검수 세션이 `Edit(sift-api/**)` deny라 **이 레포의 검증 관행(옛 구현을 일시 주입해 새 테스트만 실패하는지 보는 것)을 실행할 수 없었다.** `git worktree --detach`로 `.worktrees/`(deny 경로 밖)에 별도 트리를 파서 돌리는 절차를 REVIEWER.md에 명시하고, 공용 settings에 `Bash(git worktree:*)`를 허용했다. 자가검증 실패는 이 프로젝트에서 3회 실증됐다 — #21(회귀 테스트가 회귀를 못 잡음) · #35(하루 15시간 통과) · #23(e2e에서 결함 5건).
- **비고**: 구현 세션이 `sift-docs`를 못 쓰게 되면서 HARNESS §0.7 절차 3의 "BACKLOG로 분해"가 성립하지 않게 됐다 → **작업 목록의 원본을 이슈 본문 `## TODO`로 두고**(조율이 발행 시 작성), 구현 중 문서에 남길 것은 `.handoff/notes/`로 넘긴다. 세 역할을 동시에 띄울 필요는 없다 — 혼자 도는 사이클이면 런처를 **바꿔 타는 것만으로** 컨텍스트 격리와 권한 경계가 성립한다. ⚠️ 검증 중 확인: **`Write(경로)` 권한 규칙은 무효이고 `Edit(경로)`만 파일 권한 검사에 걸린다**(Claude Code가 경고로 알려줌 — Edit 규칙이 Write·Edit·NotebookEdit를 모두 커버). ⚠️ 런처와 프로파일은 **Claude Code 전용**이라 다른 CLI(AGENTS.md 경로)에서는 경계가 지침으로만 남는다. 심링크 복원 부수 효과로 홈 `settings.json`(`model`)과 메모리 1건이 두 머신에서 갈라져 있었음이 드러나 병합했다.
