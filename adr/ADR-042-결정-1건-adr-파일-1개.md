# D-042 · 결정 1건 = ADR 파일 1개 (2026-08-06 · D-023·D-036 문서 분할 항목 개정)

> [ADR 인덱스](README.md) · 결정 ID: D-042

- **결정**: 단일 `adr/decisions.md`를 폐지하고, 결정마다 `ADR-번호-설명.md` 파일을 둔다. `adr/README.md`는 최신순 탐색 인덱스이며, 각 ADR 파일이 해당 결정의 유일한 원본이다.
- **결정**: 기존 D-001~D-041의 번호·제목·본문을 보존하고, 문서의 직접 참조는 해당 ADR 파일로, 범용 참조는 ADR 인덱스로 갱신한다.
- **이유**: 결정이 41건으로 늘어 아키텍처·운영·과거 기록을 한 파일에서 탐색하기 어려워졌다. 결정 단위 파일은 관련 결정의 직접 링크와 개별 변경 이력을 명확히 하면서도, 인덱스 하나로 단일 진입점을 유지한다.
- **비고**: D-023과 D-036의 "분할 보류·기각" 판단은 당시 파일 규모와 운영 조건에 대한 기록으로 보존한다. 이번 분할은 그 문서 구조 판단만 개정하며, 기존 결정의 본문은 다시 쓰지 않는다.
