# D-010 · GitHub 협업 흐름 채택 (2026-06-30)

> [ADR 인덱스](README.md) · 결정 ID: D-010

- **결정**: 작업 단위마다 이슈 → 브랜치 → PR → 리뷰 → 병합. **이슈 1개 = 루프 1회분 = PR 1개**(입도), 이슈→BACKLOG 분해는 에이전트. main 직접 커밋 금지(브랜치 보호). 규칙은 [HARNESS §0.7](../references/harness.md).
- **이유**: 사용자 워크플로우 요구 + 포트폴리오 활동 기록. 루프 *성립* 필수는 아니나, 의도적 통합 레이어로 추가.
- **비고**: gh CLI 설치·인증 + main 보호 설정이 선결. 병합 실행은 초기 사람(추후 에이전트 승격 가능).
