# PR 체크리스트

> PR을 열기 전 🔧 구현 세션이 확인한다. 검수(👀)와 병합(👤)의 판단 근거이기도 하다.
> 절차 전체는 [HARNESS §0.7](../references/HARNESS.md) · 역할은 [roles/](../roles/)

## ■ REQUIRED — 예외 없음

- [ ] `./gradlew build` 성공
- [ ] 전체 테스트 통과 (증가분도 함께 적는다 — 예: `205 tests`)
- [ ] CI `build & test` green (main·develop 양쪽 required)
- [ ] 커밋이 `{type}: {한국어 요약}` 한 줄, **트레일러 없음**(에이전트 서명 금지 — D-026)
- [ ] PR 본문에 `close #N` + `## Check list`, assignee·타입 라벨 지정
- [ ] `ApplicationModules.verify()` 통과 (모듈 경계 — 자동이지만 실패 시 원인 파악까지)

## □ OPTIONAL — 해당하면

- [ ] 배치 처리량·소요시간 측정치를 PR 본문에 기록 (원칙 5 — 측정 먼저)
- [ ] 👤 `ultrareview` 요청 (과금·사용자 전용)
- [ ] 의존성을 추가했다면 **왜 필요한지**와 대안 검토를 본문에

## ◇ CONDITIONAL — 조건에 걸리면 반드시

각 항목은 **실제로 데인 사례**에서 나왔다.

| 조건 | 확인할 것 | 근거 사례 |
|---|---|---|
| **스키마가 바뀐다** | `ddl-auto: update`는 **nullable 컬럼 추가만 자동 반영**한다. 유니크 제약·인덱스는 **소급 생성되지 않는다** — 기존 DB에서 `ON CONFLICT`가 터진다 | D-029 실측 (PR #24·#30) |
| **구조가 바뀐다** (모듈·유스케이스·포트) | `sift-api/docs/`의 해당 설계 문서를 **같은 PR에서** 갱신. 다이어그램도 정합 대상 | D-017 · D-021 |
| **모듈 경계를 넘는다** | named interface로만 노출했는가, `allowedDependencies`를 열었는가. internal 직접 참조는 금지 | #29 (PR #30) |
| **식별·정규화 규칙이 바뀐다** | 기존 데이터의 키가 무효해진다 → **백필이 필요한지 실측**하고, 필요하면 같은 PR에 넣는다 | #37 (PR #38) — 재수집 시 중복 행 |
| **시각·시간대에 의존한다** | 테스트가 **실행 시각과 무관하게** 결함을 잡는가. 존 고정만으로는 부족하다 | #35 (PR #36) — 하루 15시간은 통과하던 결함 |
| **배치 Job/Step을 추가한다** | Micrometer 계측을 붙였는가 (`.coderabbit.yaml` 규칙) | #14 · #31 |
| **재실행될 수 있다** (배치·시더·러너) | 두 번 돌려도 같은 결과인가. 동시 기동 시 한쪽이 죽지 않는가 | #21 · #39 — conflict-ignore 부재 |
| **되돌려야 할 수 있다** | 되돌리는 방법을 본문에 적는다. 배포 인프라가 없으므로 현재는 **revert PR**이 유일한 수단 | D-025 |

## 회귀 방어 — 결함 수정 PR이면

새 테스트가 **정말 그 결함을 잡는지** 확인한다. 이 레포의 방식은 **옛 구현을 일시 주입해 돌려 보는 것**이다.

- #35: 새 테스트 2건만 실패, 나머지 178건 통과 → 기존 테스트로는 못 잡던 결함임이 증명됨
- #37: 새 테스트 8건만 실패, 기존 19건 통과 → dedup 오병합의 실재가 증명됨

결과를 PR 본문에 남긴다. "테스트를 추가했다"보다 "이 테스트가 이 결함을 잡는다"가 검증이다.

## CodeRabbit 리뷰 공백 확인

체크가 `SUCCESS`여도 **리뷰가 비어 있을 수 있다** — rate limit이 걸려도 통과로 뜬다(PR #22·#28·#38·#40에서 4회 재발).

```bash
gh api repos/siftnews/sift-api/pulls/{N}/comments --jq 'length'
gh api repos/siftnews/sift-api/issues/{N}/comments --jq '.[].body' | grep -i 'rate limited\|limit reached'
```

리뷰가 0건이면 **base 최신화 머지 커밋을 push해 재트리거**한다 (PR #40에서 확인 — 에이전트가 쓸 수 있는 유일한 재시도 수단).
