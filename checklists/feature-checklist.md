# 기능 작업 체크리스트

## 설계
- [ ] 영향 모듈·도메인·계약을 확인했다.
- [ ] API, DB, 보안, 캐시, 메시지, 배치 영향 여부를 판정했다.
- [ ] 사용자 결정이 필요한 설계 분기를 보고했다.

## 구현·검증
- [ ] 정상·실패·경계 사례 테스트를 추가 또는 갱신했다.
- [ ] 빌드와 전체 테스트가 통과했다.
- [ ] 포맷과 정적 분석을 통과했다.
- [ ] public 인터페이스·DTO·enum을 별도 파일로 분리하고 선언 레이아웃을 코드 규약에 맞췄다.
- [ ] REST API라면 `/api/v{major}` 버전, 오류 계약, 입력 검증을 확인했다.
- [ ] 구조 변경 시 설계 문서·다이어그램을 갱신했다.
