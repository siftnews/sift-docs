# 데이터베이스 설계

현재 엔터티·테이블·제약 조건의 상세 원본은 [MVP-DESIGN](mvp-design.md)이다. 데이터 소유권은 모듈 경계를 따라가며, 다른 모듈이 테이블을 직접 공유하지 않는다.

## 스키마 변경 규칙
- 변경 전 기존 데이터, nullability, unique 제약, 인덱스, 롤백 가능성을 검토한다.
- 자동 DDL에 인덱스·제약 생성을 기대하지 않는다. 필요한 DDL/마이그레이션을 명시한다.
- 키·정규화 규칙 변경은 백필과 재실행 안전성을 실측한다.
- 쿼리 변경은 실행 계획 또는 측정 근거 없이 성능 개선으로 주장하지 않는다.
